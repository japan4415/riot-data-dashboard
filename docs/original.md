# riot-data-dashboard

このアプリケーションはriotによって提供されているriot社のゲームにおける自分のアカウントのデータを分かりやすく表示するものである。
ユーザーはriot社にデータ開示を要求し、送られて来たzipファイルのデータを当アプリケーションにアップロードしてデータを閲覧する。

## アプリケーションのデプロイ
アプリケーションはCloudflare WorkersにCloudflare Buildsを使用してmainへのmergeによって反映される。
デプロイにはcfコマンドを使用し、wranglerは極力使用しない。
